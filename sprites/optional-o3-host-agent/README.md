# Optional O3 host agent: NOT a default route

Under the locked Universal Observation principle (architecture document, tab "Universal Observation (locked)"),
Density observes from the outside by default (O0 ambient, O1 ordinary requests). An installed agent is an O3
*granted inside view*: it is used only when a system's owner explicitly chooses to grant it, and never as the way a
kind of system is connected.

This agent was built on 25 Nov 2026 as a default host route, then reversed: its route proposals were rejected in the
kernel, and its account, keys and database logins were removed from both Sprites. The default host route is
`host.external` (outside-in). The code is kept here, unused, as a reference for a future, explicitly granted O3 tier.
